# Multi Timer App

A cross-platform, always-on-top desktop stopwatch and countdown application built with C# and Avalonia UI. Originally designed for tracking Data Structures and Algorithms (DSA) practice sessions.

## Features
* **Frameless UI:** Ultra-slim custom title bar that merges application controls with the OS window controls to maximize screen space.
* **Side-by-Side Layout:** Timers automatically wrap horizontally to save vertical space.
* **Responsive Minimalist Mode:** Shrinking the application width automatically hides text inputs and buttons, leaving only the active running clocks visible.
* **Dual Modes:** Create individual Stopwatches or Countdowns on the fly.
* **Always-On-Top:** Floats above IDEs and browsers for constant visibility.
* **Standalone Deployment:** Published as a single, self-contained executable requiring no external dependencies.

## Technologies
* C#
* Avalonia UI (.NET)
